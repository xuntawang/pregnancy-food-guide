# 孕期个护用品速查功能设计

## 1. 目标

在现有“孕期饮食速查”单页工具中增加“个护”频道，让孕期用户可以：

- 搜索成分、品类、品牌和具体商品；
- 浏览护肤、洗护、彩妆、日用品、美甲染烫和美容项目；
- 粘贴当前包装上的成分表，获得确定性规则匹配结果；
- 查看结论的使用条件、证据出处、核准日期和更稳妥的替代建议。

本功能提供日常风险沟通和信息整理，不替代产科医生、皮肤科医生、药师或毒物/暴露咨询服务。

## 2. 产品原则

1. **结论可追溯**：所有“建议避免”和“限制使用”结论必须关联权威来源及最后核准日期。
2. **按实际暴露判断**：同时考虑浓度、使用频率、部位、面积、皮肤是否破损、留敷或冲洗、吸入风险和孕期阶段。
3. **不把研究不足当作安全**：证据不足时使用独立状态，不强行归入“可用”或“禁用”。
4. **不把争议当作禁忌**：网络争议成分只有在可靠证据支持时才提高风险等级。
5. **商品配方有版本**：品牌商品结论只适用于已核对的地区、配方版本和核准日期。
6. **本地确定性处理**：成分表解析和规则匹配完全在浏览器内完成，不上传文本，不由 AI 临时生成医学结论。

## 3. 信息架构

页面顶部增加一级频道切换：

- 饮食
- 个护

采用顶部双频道方案，不增加独立首页。打开页面后恢复用户上次使用的频道；首次访问默认显示饮食频道。

个护频道包含三个入口：

1. **直接搜索**：品牌、商品、品类、中文成分名、英文名或 INCI 名。
2. **分类浏览**：护肤、洗护、彩妆、口腔与日用品、香氛、美甲染烫、美容项目。
3. **成分表筛查**：粘贴完整成分表后逐项匹配规则库。

## 4. 状态分级

个护结论使用四级状态：

| 状态 | 含义 | 展示要求 |
| --- | --- | --- |
| 通常可用 | 按标签和常规用法使用时，现有证据未显示需要特别避免 | 仍显示适用条件和一般注意事项 |
| 限制使用 | 风险取决于浓度、面积、频率、孕期阶段、通风或是否冲洗 | 必须明确可接受的边界和替代建议 |
| 建议避免 | 权威指南、监管资料或可靠的人体/药理证据支持孕期避免 | 必须提供来源、原因和误用后的处理建议 |
| 证据不足／咨询医生 | 数据不足、机构意见冲突、配方不明或涉及处方/医美决策 | 不输出确定安全结论，引导专业咨询 |

一个商品或成分表命中多个规则时，总状态采用最高风险等级，同时展示全部命中原因。低风险商品描述不能覆盖高风险成分规则。

## 5. 结果卡片

结果卡片至少包含：

- 名称、别名和所属类别；
- 四级状态和一句话结论；
- 使用条件：浓度、频率、部位、面积、留敷/冲洗、通风和孕期阶段；
- 重点留意的成分或操作；
- 更稳妥的替代方案；
- 权威来源链接、证据说明和最后核准日期；
- 商品的地区、配方版本及“以当前包装为准”提醒；
- 误用或已经暴露后的下一步建议。

搜不到具体商品时，不推断配方，提示用户粘贴当前包装成分表。

## 6. 数据结构

### 6.1 成分规则

每条规则保存：

- 唯一标识；
- 中文名、英文名、INCI 名和常见别名；
- 所属成分家族；
- 默认状态；
- 适用条件与可改变状态的暴露条件；
- 孕早期专项提示；
- 结论、原因和替代建议；
- 来源标识列表；
- 最后核准日期。

成分家族规则用于覆盖视黄醇、视黄醛、维 A 酸类等相关别名，但具体成分可以覆盖家族默认值。

### 6.2 商品快照

每条商品保存：

- 品牌、商品名和搜索别名；
- 销售地区；
- 配方版本或核对日期；
- 已核对的完整成分表；
- 对应的成分规则命中结果；
- 配方来源；
- 快照是否仍在有效期内。

商品快照超过复核周期或配方来源不可访问时，搜索仍可命中商品名，但结论降级为“核对当前成分表”。

### 6.3 品类和美容项目

品类/项目规则覆盖没有统一成分表的场景，例如染发、烫发、美甲、光疗甲、角蛋白拉直、果酸焕肤、激光脱毛和医美注射。规则必须同时说明接触方式、通风、皮肤完整性和是否应由医生评估。

### 6.4 来源

来源表保存机构、标题、URL、发布日期或更新日期、访问日期和适用主题。品牌官网和包装只用于配方核对，不用于独立证明孕期安全。

## 7. 成分表解析

解析器执行以下确定性步骤：

1. 统一全角/半角标点、大小写、空白和换行；
2. 识别中文顿号、逗号、分号、英文逗号和括号；
3. 保留括号内常见 INCI 补充名；
4. 用精确别名表匹配成分规则；
5. 对相似但不确定的名称只显示候选项，不自动判定；
6. 输出最高风险总状态、全部命中项和未识别项数量。

未命中重点风险规则时，文案必须为“当前规则库未发现已知重点风险成分”，不得写成“绝对安全”。

## 8. 首版内容

首版目标：

- 80–100 个重点成分或成分家族；
- 40–60 个日常品类和美容项目；
- 30–50 个已核对配方版本的常见商品。

内容覆盖：

- 护肤：保湿、美白、抗老、祛痘、酸类、防晒、面膜；
- 洗护：洗发、护发、去屑、沐浴、私处清洁；
- 彩妆：底妆、唇妆、眼妆和卸妆；
- 日用品：牙膏、漱口水、止汗剂、香水和驱蚊产品；
- 美甲染烫：指甲油、光疗甲、卸甲、染发、烫发和角蛋白拉直；
- 美容项目：化学焕肤、激光脱毛和医美注射；
- 重点成分：维 A 类、氢醌、水杨酸及其他酸类、过氧化苯甲酰、壬二酸、防晒剂、精油、甲醛及释放体、染发相关成分、香精和防腐剂。

对未核对配方的品牌或商品，只提供搜索别名、品类信息和成分表筛查入口。

## 9. 证据层级

使用顺序：

1. 中国国家药监局、正式药品说明书及中国妇产科/皮肤科正式指南；
2. ACOG、FDA、EMA、NHS 等监管或专业机构；
3. MotherToBaby、UKTIS/BUMPS 等孕期暴露专业资料；
4. 系统综述和专业学会共识，用于补充指南空白。

首批基础来源包括：

- [ACOG：Skin Conditions During Pregnancy](https://www.acog.org/womens-health/faqs/skin-conditions-during-pregnancy)
- [FDA：Cosmetics & Pregnancy](https://www.fda.gov/cosmetics/resources-consumers-cosmetics/cosmetics-pregnancy)
- [MotherToBaby：Topical Acne Treatments](https://mothertobaby.org/fact-sheets/topical-acne-treatments-pregnancy/)
- [NHS：Using Hair Dye in Pregnancy](https://www.nhs.uk/best-start-in-life/pregnancy/using-hair-dye-in-pregnancy-is-it-safe/)

实施阶段必须针对每一条限制/避免规则找到直接支持该结论的来源，不能只用上述概览页面推导全部成分。

## 10. 安全边界

- 误食、严重过敏、呼吸困难、眼部化学暴露或大量急性暴露时，提示立即联系医生、急救或当地毒物咨询服务。
- 处方药、治疗性外用药、严重皮肤病和医美项目默认要求医生评估。
- 不因为一次意外使用就使用“已经伤害胎儿”等恐吓性表达。
- 医学免责声明在个护频道结果区和页面底部均可见。
- 不保存用户粘贴的成分表，不收集健康信息。

## 11. 技术边界

- 保持单个静态 HTML 文件和现有 GitHub Pages 发布方式；
- 不增加服务器、账号、数据库、远程 AI 请求或 OCR；
- 饮食和个护使用独立数据集，但共享搜索、筛选、卡片和无结果组件；
- 使用浏览器本地存储仅保存上次频道，不保存查询文本；
- 所有功能在移动端优先，支持键盘操作、可见焦点和减少动态效果偏好。

## 12. 验收标准

1. 饮食/个护频道可以切换，并恢复上次频道。
2. 饮食现有搜索、筛选和内容不发生回归。
3. 品牌、商品、中文名、英文名、INCI 名和别名都能命中对应结果。
4. 中文和英文混合标点的成分表可以稳定拆分。
5. 多规则命中时，总状态始终采用最高风险等级。
6. 相似但不确定的名称不会被自动当作精确命中。
7. 所有“建议避免”和“限制使用”规则均有直接来源及核准日期。
8. 商品配方版本、地区和过期提示正确显示。
9. 未命中时不使用“绝对安全”表述。
10. 手机尺寸下搜索、分类、详情和成分表筛查均可操作。
11. 公开 GitHub Pages 链接无需登录，移动端请求返回成功并显示正确页面标题。
