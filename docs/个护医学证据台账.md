# 个护医学证据台账

> 复核日期：2026-07-28。供孕期个护成分速查使用，不替代产科、皮肤科、牙科或药师的个体化建议。“通常可用”指按标签和正常外用场景未发现需要因孕期停用的信号，不等于对任意浓度、任意复方或误食作保证。

## 来源范围与判定方法

- 一手机构与正式指南：国家药品监督管理局、ACOG、FDA、NHS、MotherToBaby、CDC/NIOSH、欧盟 SCCS、ADA。
- 补强证据：PubMed 或 PubMed Central 可核查的系统综述、专业综述与正式药品说明书。
- safe、limit、avoid、consult 分别映射为“通常可用、限制使用、建议避免、证据不足”。证据不足、成分家族过宽或市场合规状态不同的条目保守标记为咨询。
- 规则按医学结论或暴露场景拆分；例如处方外用维A酸、化妆品视黄醇、不同防晒滤剂、消费者偶尔美甲与职业溶剂暴露分别记录，没有复制同一条结论凑数。

- 国家药监局《化妆品安全技术规范（2015年版）》官方 PDF 可通过直接链接定位并在检索层读取相关条款，但本次网页正文解析器返回内部错误，无法稳定逐页展开。台账保留官方 PDF 直链，并以国家药监局标签管理公告、安全评估技术导则、禁用原料目录公告和高风险新原料政务服务说明交叉补强。该技术规范证明禁限用、准用防腐剂/防晒剂/染发剂及其条件，不单独证明孕期结局。
