# 个护医学证据台账

> 复核日期：2026-07-28。供孕期个护成分速查使用，不替代产科、皮肤科、牙科或药师的个体化建议。

## 判定契约

- `clinical-pregnancy`、`pregnancy-teratology`、`drug-label`、`pregnancy-review` 和 `occupational-pregnancy` 是孕期医学证据；`general-regulation` 与 `formulation-safety` 只说明一般监管或配方安全，不能单独支持孕期结论。
- `safe` 必须至少有一项直接孕期临床、畸胎学或孕期综述证据；`limit` 与 `avoid` 必须至少有一项孕期医学证据。
- `consult` 必须有直接孕期医学资料，或一条成分特异、含检索词、检索资源、日期与结论的 `search-gap` 记录。
- 冲突时采用最高风险的权威孕期建议。ACOG 点名建议在可能时避免 phthalates、parabens、oxybenzone、triclosan，并建议选择 fragrance-free 产品。
- 职业美甲混合暴露不外推为偶尔消费者使用结论；FDA M020 与 NMPA 浓度框架不外推为 octocrylene 或 homosalate 的孕期限制阈值。

## 访问与检索缺口

- 国家药监局《化妆品安全技术规范（2015年版）》与 FDA 防晒专论 M020 保留官方直链，仅用于一般监管框架，不单独证明孕期结局。
- 检索缺口是本项目在 2026-07-28 对 ACOG、MotherToBaby、NHS 权威资源的成分特异复核记录，不把“未检得”解释为安全，也不把搜索结果摘要作为医学来源。
- 任何后续获得的成分特异孕期人类证据，应先更新来源的 `evidenceType` 与规则来源，再考虑调整状态。
